This section documents application-owned APIs that can be reused while extending the template. Import paths use the `@/*` alias configured in `tsconfig.json`.

## Import examples

```tsx
import { Button } from "@/components/ui/button";
import { getDocsCollection } from "@/lib/docs-collections";
import type { NavLink } from "@/lib/site-config";
```

> Note: The template is an application, not a published package. These APIs are internal contracts for this codebase. If you publish them as a library, add a package entry point and semantic-versioning policy.
